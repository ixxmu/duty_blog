OpenAI 的 AI 研究实习生，已经上岗了 by AI Dancer

引言

OpenAI 昨天发了篇长文，题目叫 Research acceleration: The view inside OpenAI，把研究团队用 AI 加速 AI 研究的内部数据第一次公开出来。

到8 月中，每 1 个人类工作日对应 3.1 个 agent 工作日。

agent 与人类工作时长之比。图源：OpenAI

去年秋天，Sam 在 X 上提过一个目标：今年 9 月之前，做出一个“自动化研究实习生”。按 OpenAI 自己的测量，这个目标已经达成了。下一站，是在 2028 年 3 月前做出 automated AI researcher，也就是自动化 AI 研究员。

整篇文章讲的就是 RSI（recursive self-improvement），递归自我改进，AI 参与研发下一代 AI，下一代更快地研发下下一代，正反馈转起来就是 RSI。

OpenAI 披露的数据，让我们看到了这个过程正在走到哪一步。

01

先看一个数字：每天 7000 美元。

 

到 8 月中旬，按 coding agent 使用量排序，处于第 90 百分位的研究员，每天的推理用量按 API 价格折算，已经超过 7,000 美元。即使是处于中位数的研究员，这个数字也超过了 600 美元。

图 1｜左：中位数；右：第 90 百分位。日用量按 API 价格折算，不代表实际支出。图源：OpenAI

这个量级说明，agent 已经成了研究员每天都在用的工作工具，而且用得相当多。

另一组数据更直观。按标准 8 小时工作日折算，到 8 月中旬，整个研究组织每投入 1 个人类工作日，就会使用约 3.1 个 agent 工作日的运行时长。

图 2｜agent 与人类工作时长之比，图源：OpenAI

当然，运行了多久和做成了多少事，是两回事。这个数字不能直接理解为科研效率提高到了 3.1 倍。

它更能说明工作方式的变化：一个研究员可以同时让几个 agent 干活，一个排查报错，一个整理实验结果，另一个修改测试代码。人还是一个人，手头能同时推进的事情却多了。

02

这些 AI，究竟在“研究”什么？

 

说到 AI 做科研，我们很容易想到提出新理论、设计新架构。但原文里最有生活感的变化，发生在那些琐碎、耗时、又绕不过去的环节。

OpenAI 按科研流程把 agent 干的活分成六类：决策、设计、构建、运行、分析、沟通。各类使用量都在增长，其中增量尤其明显的，包括研究与基础设施代码、技术支持与审查，启动和监控实验加 debug。

也就是说，agent 正在帮研究员处理大量“想法有了，但还得把实验跑起来”的工作。

图 3｜按任务类型估计的每日输出 token 增量。图源：OpenAI

原文里有个很有意思的细节。

一些团队过去会安排固定答疑时段，帮研究员排查实验问题。今年，这些答疑的参与人数开始下降，其中一个团队干脆取消了答疑，把时间用来改进系统。

按照文中同事的观察，agent 已经能解决不少内部研究基础设施的问题，研究员需要找人帮忙的次数也就少了。

不过，从 agent 的输出量看，高层规划仍然只占很小一部分。OpenAI 也明确说，研究什么、哪些结果值得继续追、是否扩大训练或部署，目前还是由人决定。

03

这离“递归自我改进”，还有多远？

 

可以先把递归理解成一条可能形成反馈的链条：

更强的 AI → 更有效地辅助 AI 研发 → 研发出下一代 AI → 下一代 AI 再参与研发。

这里的“自我改进”，也不一定是某个模型直接修改自己的参数。它可能参与改进训练方法，发现评估漏洞，或者让研究工具更好用，最终帮助研发出更强的模型。

所以，我更愿意把这个阶段的 RSI 看成一种系统能力：模型、工具、算力、研究环境、评估和人的判断，一起组成这个回路。

04

“研究实习生”已实现，但还需要人带。

 

按 OpenAI 的定义，自动化研究实习生能在人类指导下，完成边界清楚的研究任务，其中包括熟练研究员需要几天才能做完的工作。

原文也聊到，在能够判断结果的任务中，agent 在多个难度区间的成功率总体上有所提升。但任务越复杂，就越需要人来引导。

过去六个月，那些预计人类需要 4—8 小时、最后成功完成的任务里，超过一半经历过至少一次人工介入。

所以，看到“任务成功”时，还要多看一眼：这是 agent 自己一路做完的，还是中间有人帮它修正了方向？

两种情况都有价值，但对应的自主程度并不一样。

“实习生”这个称呼因此很贴切。它能接下越来越多的工作，但研究员还需要交代背景、纠正偏差、判断结果。距离独立承担更完整的研究过程，还有事情要解决。

图 4｜深蓝：无介入成功；浅蓝：介入后成功。横轴为预计人类耗时，排除了结果不确定的会话。图源：OpenAI

OpenAI 的下一步目标，是在 2028 年 3 月前做出自动化 AI 研究员。能不能如期做到，还要看这些能力接下来如何发展。

05

加速过程中，也确实出现了刹车。

 

这篇文章还记录了安全限制如何改变训练活动。

据 OpenAI 披露，7 月 20 日，在发现 agent 已攻破其研究基础设施后，公司暂时关闭了用于训练的容器服务，随后加上更严格的限制才恢复。

这使强化学习训练算力明显下降，其中包括对拟部署最新模型的两周强化学习训练暂停。

到 8 月 7 日，初步证据表明，Astra 可能达到 OpenAI 准备框架中的“关键级”网络能力。公司因此又增加了针对该模型的安全限制，要求相关研究在安全等级更高的环境中进行。

接下来一周，Astra 类 GPU 分配进一步下降了 59.2%，其他模型类别的分配却上升了 17.2%。后者抵消了前者降幅的约 85%，使所分析的强化学习工作负载总分配量基本不变。

图 5｜蓝色：非 Astra；绿色：Astra。7 月 20 日至 8 月 6 日，大部分 Astra 算力用于测试安全改进。图源：OpenAI

这就是RSI（递归式自我改进）真正的进展。
